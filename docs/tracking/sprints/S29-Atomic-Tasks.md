## 3. 执行顺序建议
1. 先完成 `US-11142`、`US-11143`、`US-11144`，优先清掉 RC 与安全暴露面。
2. 再推进 `US-11145`、`US-11146`，完成第一批主链路持久化。
3. 最后完成 `US-11147`、`US-11148`，以重启恢复测试和台账收口完成验收。

## 4. 验收关注点
1. 不得因为持久化改造破坏现有 learner flow、release gate 与可观测性回归。
2. 鉴权与 RBAC 收紧后，需保留可配置的演练/调试路径并写明默认行为。
3. 所有新的 Story 状态流转必须同步更新 `backlog.csv` 与 `activity-log.csv`。
