## 3. 出口标准
1. strict-codes summary 与 JSON 输出均包含 `schema_version` 和 `schema_url`。
2. `docs/tracking/schemas/tracking-governance-strict-codes-summary.schema.json` 可用于约束 strict-codes summary 字段结构。
3. `run-node-test-summary.sh` 支持多测试文件聚合统计，失败时回放完整日志。
4. PR 评论异常排序支持 `QUALITY_GATE_PR_COMMENT_ABNORMAL_PRIORITY_MATCH=contains|exact`，非法值可回退默认行为。
5. S21 台账完整并追加 `REL-058`。
