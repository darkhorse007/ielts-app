## 3. S21 执行顺序建议
1. 先完成 `US-11051~US-11057`，交付 schema_url/schema 与 Node 单测摘要聚合。
2. 再完成 `US-11058`，交付 PR 评论优先级匹配模式切换能力。
3. 最后完成 `US-11059~US-11060`，文档同步与发布收口。

## 4. S21 验收门槛
1. strict-codes 输出包含 `schema_version` 与 `schema_url`。
2. strict-codes summary schema 文件可被下游引用。
3. Node 单测摘要脚本支持多文件聚合并在失败场景回放完整日志。
4. PR 评论异常模式支持 `contains|exact` 匹配与 fallback。
5. S21 台账与发布记录完整且校验通过。
