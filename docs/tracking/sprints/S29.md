1. 补齐 Postgres smoke、RC 验收清单与发布记录的最后一段闭环。

## 3. 出口标准
1. `npm run smoke:postgres:e2e-local` 或等效外部 Postgres 验证通过，并完成 RC 清单签署留档。
2. `/admin` 在未登录态不可直接访问；system 级接口具备默认收紧且可显式配置的 RBAC 策略。
3. `auth/account/onboarding/progress` 的核心主链路数据完成 repository 化并支持服务重启后恢复。
4. learner 主链路浏览器级回归与重启恢复集成测试全部通过。
5. `release:checklist`、tracking 治理校验与 S29 台账同步保持绿色。
