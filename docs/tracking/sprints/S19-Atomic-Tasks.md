## 3. S19 执行顺序建议
1. 先完成 `US-11031~US-11035`，交付 strict-codes 输出模式与单测接入。
2. 再完成 `US-11036~US-11037`，交付 PR 评论异常步骤优先级排序。
3. 最后完成 `US-11038~US-11040`，文档同步与发布收口。

## 4. S19 验收门槛
1. strict-codes 支持 `output_mode` 并保持 JSON 机读稳定。
2. strict-codes Node 单测纳入 release 脚本测试链路。
3. PR 评论异常模式按优先级排序后限幅展示。
4. S19 台账与发布记录完整且校验通过。
