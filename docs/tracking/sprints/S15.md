## 3. 出口标准
1. `npm run validate:tracking-governance:strict-codes` 可独立校验 strict code 配置。
2. `release:checklist` 在 strict 模式下可前置执行 strict code 预检步骤。
3. `tracking-governance-fix-template --dry_run true --output_format json --out <file>` 可输出 JSON 文件且不落盘模板目录。
4. PR 评论在 tracking artifact 缺失时提供专项 triage 提示。
5. S15 台账完整并追加 `REL-052`。
