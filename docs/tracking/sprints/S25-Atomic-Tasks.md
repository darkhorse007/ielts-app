## 3. S25 执行顺序建议
1. 先完成 `US-11091~US-11094`，交付 env-file 解析增强与回归。
2. 再完成 `US-11095~US-11097`，完成 schema 契约收紧与门禁验证。
3. 最后完成 `US-11098~US-11100`，补齐值班模板、台账与发布收口。

## 4. S25 验收门槛
1. env-file 支持转义与尾随注释，quoted 尾随非法内容有明确失败提示。
2. strict-codes schema 增加 unknown 字段约束并通过契约回归。
3. runbook 提供 exact 命中示例与一键排障命令。
4. `test:release-scripts` 与 strict `release:checklist` 全通过。
5. S25 台账与发布记录完整且治理校验通过。
