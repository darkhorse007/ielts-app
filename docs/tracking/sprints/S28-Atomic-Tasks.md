## 3. S28 执行顺序建议
1. 先完成 `US-11131~US-11135`，把“真实进度展示”与“部署配置就绪”打平。
2. 再完成 `US-11136~US-11138`，补足主链路 E2E 与 Postgres 执行基线。
3. 最后完成 `US-11139~US-11140`，形成 RC 验收包并做一次正式收口。

## 4. S28 验收门槛
1. tracking 总览不再出现明显的 Epic/Story 状态失真。
2. 前端 API / WS 地址完成 env 化且保留本地默认值兼容。
3. Playwright 覆盖两条关键业务闭环，并纳入脚本入口。
4. Postgres 集成验证具备明确的本地或夜间执行基线。
5. RC 验收清单与发布记录可直接驱动一次候选发布演练。
