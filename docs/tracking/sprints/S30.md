# Sprint S30（Practice Persistence & Recovery II）

## 1. Sprint 目标
1. 将 listening/reading practice、retry queue 与 speaking realtime session 从内存态切换为可持久化仓储。

4. 收敛多仓储运行时配置、runbook 与 release smoke 组合，降低下轮 RC 收口成本。

## 3. 出口标准
1. practice / speaking / writing / mock 的核心状态具备 Postgres 后端能力，并可通过环境变量启用。
2. 对应主链路在服务重启后可恢复关键状态或继续执行，不再依赖纯内存存活。
3. `smoke:postgres:e2e-local` 或新增 smoke 入口覆盖扩展后的持久化验证。
4. runbook、release 记录、tracking 台账与新的存储矩阵保持一致。
