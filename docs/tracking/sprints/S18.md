## 3. 出口标准
1. strict-codes 支持 `--summary_to_stderr` 与 `--quiet`，并保持 JSON 机读输出稳定。
2. strict-codes 参数可由环境变量可靠透传（含 `require_non_empty`）。
3. quality-gate `tracking_governance.strict_codes_check` 包含 `mode` 字段并在 Step Summary/PR 评论展示。
4. PR 评论异常模式支持 `QUALITY_GATE_PR_COMMENT_ABNORMAL_MAX_STEPS` 限幅。
5. S18 台账完整并追加 `REL-055`。
