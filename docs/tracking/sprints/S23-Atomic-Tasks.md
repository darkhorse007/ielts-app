## 3. S23 执行顺序建议
1. 先完成 `US-11071~US-11074`，交付 PR 评论预览能力与回归。
2. 再完成 `US-11075~US-11077`，交付 strict-codes 契约负向测试与测试链路接入。
3. 最后完成 `US-11078~US-11080`，文档模板同步与发布收口。

## 4. S23 验收门槛
1. PR 评论预览 CLI 支持 stdout 与 `--out` 输出。
2. strict-codes schema 契约测试包含负向断言并稳定通过。
3. `test:release-scripts` 默认包含新增测试并保持摘要输出。
4. runbook 包含 exact 推荐 token 模板。
5. S23 台账与发布记录完整且校验通过。
