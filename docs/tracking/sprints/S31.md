# Sprint S31（Release Ops Polish & RC Packaging）

## 1. Sprint 目标
1. 为本地 `smoke:postgres:e2e-local` 增加 daemon 就绪预检，降低 Docker / OrbStack 未就绪时的误判成本。
2. 把 `release:checklist` 与 tracking summary 转换为可复用的 RC 交付包目录，减少候选发布的手工整理步骤。
3. 将 RC 包生成入口、runbook、FAQ 与命令矩阵统一收敛，形成“一条命令出包”的发布运维基线。
4. 在不扩张业务范围的前提下，继续保持 release checklist 与 tracking 治理闭环可追溯。

## 3. 出口标准
1. `smoke:postgres:e2e-local` 在 Docker / OrbStack 不可用时可快速给出明确失败语义，并提示外部 Postgres fallback 命令。
2. 新增 RC 出包入口可从 `release:checklist` summary 与 tracking summary 生成完整目录结构，而非仅生成 release row。
3. RC 包至少包含验收清单、已知问题模板、演示脚本、发布说明模板与 summary 副本，并保留自定义输出目录能力。
4. runbook、README、RC 模板、脚本测试与最终 release 记录对新的出包方式保持一致。
