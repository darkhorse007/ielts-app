# Sprint S17（Tracking Governance Hardening VIII）

## 1. Sprint 目标
1. 为 strict code 快速校验增加 `supported_codes` 发现模式，支持文本/JSON 输出。
2. 在 strict code summary 中补齐 `mode` 与 `duration_ms`，提升可观测性。
3. 在 quality-gate 汇总与 PR 评论中展示 strict 预检结果，并支持异常字段精简模式。

## 3. 出口标准
1. `validate:tracking-governance:strict-codes` 支持 `--supported_codes true|json`。
2. strict-codes summary 含 `mode`、`duration_ms` 字段并可供 CI 聚合消费。
