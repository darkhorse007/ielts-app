## 3. 出口标准
1. `docs/tracking/backlog.csv` 中 Epic 展示状态不再与 Story 实际完成度冲突，或已有自动校验阻断陈旧状态。
2. 前端不再在源码中硬编码 API / WS 地址；本地、CI、部署环境均可通过 env 注入配置。
3. Playwright 覆盖至少一条完整学员主链路与一条练习/模考主链路，并可在本地复现。
4. Postgres 集成测试从“默认跳过”升级为“有明确启用方式并纳入夜间或 RC 验证”。
5. 形成可直接执行的 RC 验收包，包括命令清单、已知问题模板、发布候选说明。
