## 3. 出口标准
1. quality-gate 输出并归档 `quality-gate-summary.json`，Step Summary 可直接展示失败步骤。
2. `release:checklist` 支持 `fail-fast`、`continue-on-error`、`dry-run`。
3. 本地门禁失败归档包含 `manifest.json`，可定位已采集日志与执行开关。
4. 可以通过命令生成 release 记录候选行并用于台账回填。
