# Epic Map（标准商业版首发）

## 1. 目标摘要
首发版本围绕“5.5 -> 6.5 提分闭环”组织 11 个 Epic，覆盖跨端基础设施、四科训练、AI 能力、模考、商业化、后台管理与发布保障。

## 2. Epic 总览
| Epic | 名称 | 业务结果 | 优先级 | 依赖 | 目标窗口 |
|---|---|---|---|---|---|
| E01 | 账号与跨端基础 | 打通注册登录、会话管理、云端同步 | P0 | 无 | W1-W3 |
| E02 | 诊断与动态学习计划 | 5 分钟诊断并生成 8 周计划 | P0 | E01 | W2-W5 |
| E03 | 听力训练闭环 | 题型训练 + 错因标签 + 重练队列 | P0 | E01, E02 | W3-W7 |
| E04 | 口语实时对练教练 | 实时对练、追问、四维评分与纠偏 | P0 | E01, E02 | W3-W8 |
| E05 | 阅读训练闭环 | 题型训练 + 定位证据 + 计时模式 | P0 | E01, E02 | W4-W8 |
| E06 | 写作批改闭环 | 四维评分、证据句、改写复评 | P0 | E01, E02, E04 | W5-W9 |
| E07 | 模考与复盘报告 | 全真模考、报告生成、计划回写 | P0 | E03-E06 | W6-W10 |
| E08 | 订阅与权益系统 | 试用、订阅、到期降级和跨端一致 | P0 | E01 | W6-W10 |
| E09 | 数据埋点与可观测性 | 学习指标、模型质量、告警闭环 | P0 | E01-E08 | W4-W11 |

| E11 | 后台管理系统 | 运营后台、RBAC、审计、内容与订单管理 | P0 | E01,E08,E09 | W5-W12 |

## 3. Epic 完成标准
### E01 账号与跨端基础
1. 支持手机号/邮箱登录，跨端会话有效。
2. 学习进度跨设备同步延迟 <= 5 秒。
3. 数据删除链路可用并可审计。

### E02 诊断与动态学习计划
1. 新用户诊断 <= 5 分钟完成。
2. 自动输出分项能力和 8 周计划。
3. 新训练数据产生后 2 分钟内可触发计划更新。

### E03 听力训练闭环
1. 支持目标题型并可进行回放重练。
2. 错题反馈包含错因与行动建议。
3. 错题可进入重练队列并跟踪再错率。

### E04 口语实时对练教练
1. Part 1/2/3 对练可用，支持追问。
2. 语音结束后 3 秒内输出首条反馈。
3. 每次反馈包含四维评分与可执行改进建议。

### E05 阅读训练闭环
1. 核心题型可训练并支持计时。
2. 错误反馈带定位证据或逻辑说明。
3. 复盘可按题型输出趋势。

### E06 写作批改闭环
1. Task 1/2 支持提交与评分。
2. 输出 TR/CC/LR/GRA 四维评分和证据句。
3. 改写复评支持差异对比。

### E07 模考与复盘报告
1. 全真计时模考可进行并支持断点恢复。
2. 模考结束 2 分钟内输出报告。
3. 报告结果可回写下周计划。

### E08 订阅与权益系统
1. 试用配额和订阅权益准确生效。
2. 到期降级策略延迟 <= 1 分钟。
3. 四端权益显示一致。

### E09 数据埋点与可观测性
1. 核心行为事件覆盖率 >= 95%。
2. 模型路由失败和回退指标可观测。
3. 核心链路告警规则可触发并通知值班。

### E10 跨平台质量与发布
1. 四端 P0 场景回归通过率 >= 98%。
2. 发布门禁自动校验阻断未达标版本。
3. 支持灰度发布与快速回滚策略。

### E11 后台管理系统
1. Admin 登录与 RBAC 生效，越权请求统一返回 `403`。
2. 用户冻结/解冻、订单查询、权益校正可用且可追溯。
3. 内容发布链路可执行并附审计记录。

## 4. 关键依赖关系
1. E01 完成后，E02-E08 才能进入完整联调。
2. E04 的会话能力为 E06 写作改写链路提供 Agent 运行基础能力。
3. E03-E06 是 E07 模考报告有效性的前置输入。
4. E09 必须在 E10 之前达到可观测覆盖，否则发布风险不可控。
5. E11 依赖 E01（身份体系）、E08（订单权益）、E09（审计可观测）。
6. E10 发布门禁需覆盖 E11 的后台权限与审计验证。

## 5. 资源建议
1. 客户端: 2-3 人（Flutter）。
2. 服务端: 2-3 人（API + Orchestrator + 数据）。
3. AI 工程: 1-2 人（Prompt、路由、评测）。
4. QA: 2 人（自动化 + 跨端手测）。
5. 产品/设计: 各 1 人并行支持。
6. 后台前端: 1 人（Admin Web）。
