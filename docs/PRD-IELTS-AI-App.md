# PRD: IELTS Self-Hosted Web App

## 文档信息
- 版本: v2.0
- 状态: Active Baseline
- 适用分支: `self-hosted`
- 目标形态: 自托管 Web 应用
- 客户端技术: React + Vite
- 服务端技术: Fastify + WebSocket

## 1. 产品定位
这是一个面向 IELTS 备考场景的自托管学习应用，目标是提供一套完整的“诊断 -> 计划 -> 训练 -> 反馈 -> 模考 -> 复盘”闭环。

该分支不再承担商业化、后台运营、发布治理或供应商运行时编排职责，只保留学习主链路。

## 2. 核心目标
1. 让学习者可以从注册开始，在单一 Web 应用内完成完整备考闭环。
2. 让部署方可以用最少依赖把系统跑起来，默认支持纯内存模式，按需切换到 Postgres。
3. 让代码、文档和测试围绕同一套核心能力收敛，避免保留商业版和运维版残留。

## 3. 当前范围
### 3.1 In Scope
1. 用户注册、登录、刷新、退出
2. 入门目标设置、诊断问答、计划生成与调整历史
3. 学习进度同步与冲突查询
4. 听力、阅读训练
5. 错题重练队列、播放状态恢复、阅读计时器
6. 实时口语对练、发音反馈、同题重答与对比
7. 写作批改、模板插入、改写复评与历史档案
8. 全科模考、报告生成、报告导出与计划回写撤销
9. 行为分析事件上报、汇总查询与轻量 A/B 实验
10. 个性化提醒偏好、提醒推荐与点击追踪
11. 账号资料查询、数据导出、删除申请与删除执行

### 3.2 Out Of Scope
1. 支付、订阅、会员、优惠券、家庭计划
2. Admin 后台、订单查询、权限校正、内容审核发布
3. 发布治理、灰度、稳定性演练、混沌测试、回滚控制台
4. Provider runtime 管理、支付 webhook runtime、system RBAC
5. 应用商店分发、桌面原生打包、多端商业化发布

## 4. 目标用户
1. 需要自托管 IELTS 练习环境的团队或个人
2. 希望演示或验证完整 IELTS 学习闭环的开发者
3. 需要在本地或私有环境中部署训练系统的实施方

## 5. 关键用户流程
### 5.1 新用户入门
1. 注册账号
2. 登录
3. 填写目标分数、考试日期、每周学习时长和薄弱项
4. 完成诊断问答
5. 获得能力估计与激活中的学习计划

### 5.2 日常训练
1. 查看首页和当前计划
2. 进入听力或阅读训练
3. 提交答案并获得结构化反馈
4. 将错题加入重练队列
5. 再次发起重练并观察熟练度变化

### 5.3 口语训练
1. 创建实时口语会话
2. 通过 WebSocket 进行对练
3. 查看会话摘要、事件流与发音反馈
4. 需要时发起同题重答并查看对比

### 5.4 写作训练
1. 选择 Task 1 或 Task 2
2. 提交作文获取评分
3. 使用模板插入辅助重写
4. 进行改写复评并保存档案

### 5.5 模考与复盘
1. 创建模考
2. 保存分科进度
3. 中断后恢复
4. 提交模考并生成报告
5. 把报告结果回写到学习计划
6. 必要时撤销一次回写

### 5.6 账号管理
1. 查看账户状态
2. 导出个人数据
3. 发起删除申请
4. 确认删除账号

## 6. 功能要求
### 6.1 账号与会话
1. 支持邮箱或手机号注册
2. 支持基于 refresh token 的会话续期
3. 支持登录失败计数与失效控制

### 6.2 诊断与计划
1. 支持入门目标录入
2. 支持按题提交诊断答案
3. 支持暂停、恢复、完成诊断
4. 支持查看当前生效计划和计划调整历史

### 6.3 训练
1. 听力支持播放状态保存与恢复
2. 阅读支持 training/exam 两种模式与计时器恢复
3. 训练结果可进入重练队列

### 6.4 口语
1. 支持标准口语和 role-play 两类会话
2. 支持 part 切换、结束、重答和对比
3. 支持发音反馈任务追踪
4. 支持会话恢复窗口

### 6.5 写作
1. 支持评分、证据句、建议项输出
2. 支持模板插入与采纳率统计
3. 支持改写后再评分和历史归档

### 6.6 模考
1. 支持全科模考实例创建
2. 支持进度保存与恢复
3. 支持报告导出与计划回写

### 6.7 学习支撑能力
1. 支持分析事件批量写入
2. 支持汇总查询
3. 支持提醒推荐与点击反馈
4. 支持轻量 A/B 实验配置与分流

## 7. 非功能要求
1. 默认可在纯内存模式运行，便于开发和快速演示
2. 各学习域支持独立切换到 Postgres
3. 服务端必须暴露 `/health`
4. 账号密钥必须通过 `AUTH_SECRET` 或 `AUTH_SECRET_FILE` 提供
5. 主链路自动化测试必须持续通过

## 8. 发布口径
`self-hosted` 分支的上线目标是“可部署、可验证、可自托管的 IELTS Web 应用”，不是商业 GA，也不是含支付和后台的正式运营版本。

## 9. 验收标准
1. `npm run typecheck` 通过
2. `npm test` 通过
3. 在最小内存模式下可完成注册、诊断、训练、模考、导出
4. 在 Postgres 模式下可完成认证、学习主链路与模考恢复 smoke

## 10. 明确约束
1. 不再接受“恢复支付或后台能力”的隐式需求进入该分支
2. 所有新增文档必须以当前 React/Fastify/self-hosted 架构为准
3. 若历史材料与本 PRD 冲突，以本 PRD 和代码实现为准
