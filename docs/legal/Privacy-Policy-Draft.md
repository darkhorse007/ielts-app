# 隐私政策草案（Draft for Review）

## 文档信息
- 版本: v0.2
- 状态: Draft for Review
- 创建日期: 2026-03-14
- 适用范围: 当前 `IELTS AI App` GA 候选版本
- 说明: 本文基于当前代码与工程文档整理，仅用于产品/法务/工程评审；当前首发口径已冻结为 `Stripe + Alipay`、`OpenAI` 主 provider、退款 `manual_review`、用户数据导出可用，但在正式保留策略与联签完成前，不得直接对外发布。

## 1. 我们处理哪些信息
为向您提供账号、学习、订阅、提醒和运营保障能力，我们当前会处理以下类型的信息：

1. 账号与身份信息
- 邮箱地址或手机号
- 登录密码的加密哈希
- 显示名称

2. 会话与设备信息
- `device_id`
- 登录 IP 地址
- `user-agent`
- 刷新令牌及其失效时间

3. 学习与训练信息
- 目标分数、考试日期、每周学习时长、薄弱项
- 诊断结果、学习计划、训练记录、错题与重练记录
- 口语、写作、模考等训练内容及其反馈结果

4. 订阅与订单信息
- 当前权益档位
- 订单状态、支付金额、退款金额
- 支付订单号或支付提供方返回的订单标识

5. 提醒与行为分析信息
- 平台、技能、事件类型、追踪 ID、延迟、是否触发回退等行为事件
- 个性化提醒订阅状态、推荐时间、提醒点击记录

6. 审计与安全信息
- 高风险后台操作记录
- 系统告警、稳定性处理记录
- 为保障系统安全、可追溯和风控所需的审计日志

## 2. 我们如何使用这些信息
我们当前主要将上述信息用于以下目的：

1. 完成注册、登录、会话续期、登出和账号安全控制。
2. 生成首次诊断结果、学习计划和训练反馈。
3. 支持模考报告、重练建议和学习提醒。
4. 处理订阅、权益变更、退款状态同步和后台人工校正。
5. 监控系统稳定性、处理故障、审计高风险操作和防止滥用。
6. 统计核心功能使用情况，用于改进体验和评估运营效果。

## 3. AI 处理说明
1. 本产品包含 AI 反馈、评分和计划生成能力。
2. 当前首发生产主 AI provider 冻结为 `OpenAI`，首发 fallback 默认关闭；系统保留 `LLM_FALLBACK_*` runtime 入口，但 day-1 不默认启用。
3. 为提供 AI 评分、反馈与计划生成能力，与这些能力直接相关的用户内容及必要上下文可能被发送至 `OpenAI` 处理；当前 `/v1/system/health/providers` 可只读查看 provider runtime 摘要，但不会返回密钥。
4. 正式上线版本中，我们仍将进一步披露数据处理区域、协议附件、故障回退规则以及日志和输出结果的保留规则。

## 4. 支付处理说明
1. 本产品支持订阅升级、取消续费、恢复和退款状态处理。
2. 当前首发生产支付渠道冻结为 `Stripe` 与 `支付宝（Alipay）`。
3. 当前代码已具备支付回调、订单状态流转、`PAYMENT_*` runtime config，以及基于 `x-ielts-signature` / `x-ielts-timestamp` 的验签与 replay window 基线。
4. 退款处理基线冻结为 `人工审核（manual_review）`：我们会先核对订单与支付渠道记录，再给出处理结论；不承诺后台即时退款。
5. 正式上线前，我们仍将补充披露：
- 实际支付渠道名称
- 支付回调用途
- 退款与降级规则
- 支付记录保留期限

## 5. 我们如何共享或披露信息
除非法律法规要求或为实现服务所必需，我们不会向无关第三方出售您的个人信息。当前可能发生的信息共享场景包括：

1. 向提供 AI 推理、支付处理或基础设施托管能力的服务商传递必要信息。
2. 为完成退款、风控、审计或合规义务，向依法有权的机构提供必要记录。
3. 在后台运营、客服、财务和安全处置过程中，由获授权的内部人员按角色访问必要数据。

说明：
1. 当前已冻结的处理方口径包括：支付渠道 `Stripe / Alipay`、主 AI provider `OpenAI`。
2. 正式发布版仍需把基础设施托管、协议附件与保留期限补充为完整名单和正式条款。

## 6. 数据保留与删除
### 6.1 当前工程基线
根据当前架构与数据草案，系统已有以下保留/归档目标：

1. 行为分析明细默认保留 `12 个月`。
2. 训练会话热数据默认保留 `180 天` 后归档。
3. 支付与审计日志长期保留。

### 6.2 当前删除能力
1. 您可以发起注销申请。
2. 您可以通过确认删除动作删除账号。
3. 删除后，系统会撤销既有会话，并清理目标、计划、训练、模考、权益、订单、提醒及部分分析相关数据。
4. 您可以通过 `GET /v1/users/me/export` 获取当前账户范围内的 JSON 数据副本。

### 6.3 仍待补齐的事项
1. 正式的删除 SLA（例如多少小时内完成）尚未冻结。
2. 审计日志、支付记录、分析日志和备份中的删除例外规则尚未形成最终对外文案。
3. 正式上线前，我们会补充一份单独的《数据保留与删除策略》并与本政策保持一致。

## 7. 您可以如何管理自己的信息
当前版本中，您可以：

1. 登录后查看基础账号状态。
2. 登出并使当前会话失效。
3. 发起注销申请并确认删除账号。
4. 退订学习提醒。
5. 通过 `GET /v1/users/me/export` 获取当前账户范围内的 JSON 数据副本。

当前仍待补齐或确认的能力：
1. 更完整的个人资料更正路径尚未形成正式说明。
2. 如需非 JSON 格式副本或客服代办导出，仍需补充 SOP 与对外文案。

正式发布前，我们会把 JSON 导出能力、适用范围与人工支持边界同步到用户协议和客服口径。

## 8. 安全措施
我们将采取合理的技术和管理措施保护信息安全，包括但不限于：

1. 传输链路加密。
2. 鉴权、RBAC 权限控制和高风险操作审计。
3. 后台报表导出脱敏。
4. 会话失效与异常访问控制。

说明：
1. 当前服务端已支持认证签名密钥外置化，同时已支持支付 webhook secret 与 AI provider key 的环境变量 / 文件方式注入；正式上线前仍需在生产环境完成 secret manager / 文件挂载与轮换流程落地。
2. 在生产环境 secret 管理未完成前，本文仍不能视为最终发布版隐私政策。

## 9. 未成年人说明
1. PRD 要求涉及未成年人时展示监护与时长提醒。
2. 当前仓库尚未见到正式未成年人提示或监护人同意文案与实现。
3. 若上线版本面向未成年人或可能被未成年人使用，必须在正式发布前补齐对应流程和文案。

## 10. 版权与内容来源
1. 题库内容应具备合法来源或授权。
2. 不得直接搬运受版权保护的真题原文与音频。
3. 当前仓库尚未包含可对外展示的版权授权台账，因此正式上线前必须补齐。

## 11. 本政策的更新
当我们的产品功能、外部服务供应商或数据处理方式发生重大变化时，我们会更新本政策并以适当方式通知您。
