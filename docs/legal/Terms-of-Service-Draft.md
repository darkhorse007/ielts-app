## 1. 协议适用范围
1. 本协议适用于您使用 `IELTS AI App` 的网站、客户端、后台管理端相关服务。
2. 您注册、登录、访问或使用本产品，即表示您已阅读并同意受本协议约束。
3. 若您不同意本协议，应停止注册或使用相关服务。

## 2. 服务内容
根据当前产品范围，我们提供的核心服务包括：

1. 账号注册、登录、会话续期与账号删除。
2. 目标设置、首次诊断、学习计划生成与滚动调整。
3. 听、说、读、写训练及反馈。
4. 模考、复盘报告与计划回写。
5. 订阅、试用、权益管理及后台最小运营闭环。

说明：
1. 当前产品仍处于 `RC / pre-GA` 阶段。
2. 部分能力虽然在架构或 PRD 中有规划，但只有已实际实现并上线的部分才构成正式服务内容。

## 3. 账号注册与使用
1. 您应提供真实、准确、完整且可用的注册信息。
2. 当前版本支持邮箱或手机号加密码方式注册登录。
3. 您应妥善保管账号、密码、令牌和设备信息，不得将账号借予、出租、转让或出售给他人。
4. 因您保管不善造成的账号被盗、令牌泄露或第三方使用风险，应由您及时通知我们并配合采取保护措施。

## 4. 用户行为规范
您不得利用本产品从事以下行为：

1. 违反法律法规、公序良俗或考试诚信要求的行为。
2. 通过爬虫、批量脚本、越权访问或其他技术手段干扰服务运行。
3. 绕过订阅限制、配额限制、鉴权控制或后台权限控制。
4. 上传、发布、传播违法、侵权、侮辱、骚扰或其他不当内容。
5. 将本产品的反馈、题库、界面或运营数据用于未经授权的商业用途。

## 5. AI 生成内容说明
1. 本产品包含 AI 反馈、评分、建议与计划生成能力。
2. AI 输出仅用于学习辅助，不构成官方考试评分、法律意见、医学意见或任何保证结果的承诺。
3. AI 输出可能存在不准确、不完整、延迟或不适用的情况，您应结合自身判断使用。
4. 当前首发生产主 AI provider 冻结为 `OpenAI`，首发 fallback 默认关闭；我们仍有权基于安全、合规、质量或成本原因调整 AI 路由、模型或回退策略。

## 6. 订阅、试用与权益
### 6.1 当前范围
1. 产品支持免费层、试用和付费权益。
2. 当前代码已具备升级、取消续费、恢复、支付回调和退款状态处理的基础能力。
3. 当前首发生产支付渠道冻结为 `Stripe` 与 `支付宝（Alipay）`，退款处理基线为 `人工审核（manual_review）`。

### 6.2 当前限制
1. 当前仓库已具备支付 provider runtime config、webhook 验签和重放防护骨架，但后台仍没有直接发起退款的 admin API。
2. 即使支付渠道已冻结，到账时间与最终处理结果仍以实际支付渠道记录为准。
3. 因此本草案中的订阅与退款条款仍仅构成内部评审版本，不构成最终发布承诺。

### 6.3 正式发布前需明确的事项
1. 计费周期、扣费规则和续费说明。
2. 退款适用条件、人工审核处理方式和权益回退规则。
3. 权益到期、取消续费和降级生效规则。
4. 客服/财务/法务的最终签署版本。

## 10. 账号注销与终止
1. 您可以按照产品提供的路径发起注销申请并确认删除账号。
2. 您也可以通过 `GET /v1/users/me/export` 获取当前账户范围内的 JSON 数据副本。
3. 删除完成后，相关会话将被撤销，部分用户域数据会被清理。
4. 但基于法律法规、审计、支付、风控、安全或备份管理需要，某些记录可能在合法范围内继续保留一段时间。
5. 具体保留与删除规则以正式发布的《隐私政策》和《数据保留与删除策略》为准。
