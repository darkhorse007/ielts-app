## 9. 推荐阅读顺序
1. 先读主 PRD 明确目标与范围。
2. 再读 IA/API 附录确认实现边界。
3. 再读市场与竞品调研文档，校准差异化方向。
4. 再读统一技术架构文档对齐系统设计。
5. 再读 QA 附录确认验收与门禁。
6. 然后按 Backlog 文档进入排期执行。
7. 再参考工程实施文档拆分到具体开发任务。
8. 最后在 `docs/tracking/` 中执行日常跟踪、发布与复盘。
